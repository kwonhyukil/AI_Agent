# AI Agent 처음 시작하기


이 폴더는 `AI Agent`를 단계별로 직접 만들어 보면서 배우기 위한 학습용 예제입니다.

처음 배우는 사람이라면 가장 먼저 이 문서에서 아래 3가지를 구분하면 됩니다.

## 1. AI, LLM, AI Agent는 무엇이 다른가

### AI

`AI`는 사람처럼 판단하거나 예측하는 프로그램 전체를 넓게 부르는 말입니다.

예:

- 사진 속 고양이를 찾는 프로그램
- 추천 영상을 고르는 프로그램
- 문장을 자동으로 만드는 프로그램

### LLM

`LLM`은 많은 글을 학습해서 사람처럼 문장을 만들고 이해하는 모델입니다.

예:

- Claude
- GPT

LLM은 똑똑하게 말은 잘하지만, 기본적으로는 직접 행동하지 못합니다.

예를 들어 LLM은:

- 인터넷 검색을 직접 못 하고
- 파일을 직접 저장 못 하고
- 계산을 틀릴 수도 있고
- 컴퓨터 프로그램을 마음대로 실행하지 못합니다

### AI Agent

`AI Agent`는 LLM에 `도구(tool)`와 `반복(loop)`과 `상태(state)`를 붙인 프로그램입니다.

즉, 단순히 말만 하는 AI가 아니라:

1. 목표를 이해하고
2. 필요한 도구를 고르고
3. 결과를 확인하고
4. 끝날 때까지 반복하는

형태로 동작합니다.

짧게 정리하면:

- `LLM`: 생각하고 말하는 두뇌
- `AI Agent`: 생각 + 도구 사용 + 작업 진행까지 하는 시스템

## 2. 이 폴더를 어떤 순서로 공부하면 좋은가

이 폴더는 아래 순서대로 보는 것이 가장 자연스럽습니다.

### `01_hello.py`

가장 기본적인 LLM 호출입니다.

배우는 것:

- API 키 불러오기
- 모델에 질문 보내기
- 답변 받기

핵심 질문:

- "아, 파이썬으로 AI와 대화할 수 있구나?"

### `02_tool_use.py`

LLM이 도구를 선택해서 쓰는 구조를 배웁니다.

배우는 것:

- tool 정의
- LLM이 어떤 tool을 쓸지 판단
- tool 결과를 다시 LLM에 전달

핵심 질문:

- "모델은 판단하고, 실제 실행은 누가 하지?"

정답:

- 판단은 모델
- 실행은 파이썬 코드

### `03_agentic_loop.py`

한 번 답하는 AI가 아니라, 목표를 달성할 때까지 반복하는 구조를 배웁니다.

배우는 것:

- `while` 루프
- `tool_use`가 끝날 때까지 반복
- 여러 단계 작업 처리

핵심 질문:

- "왜 Agent에는 반복 구조가 필요하지?"

### `04_practical_tools.py`

실전에서 자주 쓰는 도구를 붙여 봅니다.

배우는 것:

- 웹 검색
- 파일 읽기/쓰기
- 파이썬 코드 실행

핵심 질문:

- "AI가 실제로 일을 하려면 어떤 도구가 필요하지?"

### `05_memory_state.py`

다음 단계입니다. 에이전트가 대화와 작업 상태를 기억하는 방법을 배웁니다.

배우는 것:

- 세션별 상태 저장
- `messages`, `facts`, `tasks` 분리
- 파일을 다시 실행해도 상태 이어가기

핵심 질문:

- "왜 기억하지 못하는 Agent는 금방 한계가 올까?"

## 3. 이 폴더를 공부할 때 가장 중요한 태도

처음에는 "코드를 다 이해해야 한다"보다 아래 순서가 더 중요합니다.

1. 이 파일이 해결하려는 문제가 무엇인지 이해하기
2. 이전 파일보다 무엇이 추가되었는지 보기
3. 직접 실행해 보고 출력 변화를 관찰하기
4. 코드 세부 문법보다 흐름을 먼저 이해하기

특히 아래 흐름을 계속 머리에 두면 됩니다.

`사용자 요청 -> 모델 판단 -> 도구 실행 -> 결과 반영 -> 반복 -> 최종 응답`

이 흐름이 바로 AI Agent의 핵심입니다.

추천 순서:

- "이 파일은 왜 필요한가?"
- "이전 파일보다 뭐가 더 강해졌는가?"
